A01:2021 – Broken Access Control

Access control enforces policy such that users cannot act outside of their intended permissions. Failures typically lead to unauthorized information disclosure, modification, or destruction of data.

hacker tip: try changing an ID or parameter manually, or force browsing to admin endpoints.

A02:2021 – Cryptographic Failures

Failures related to cryptography (or lack thereof) which often lead to exposure of sensitive data. Examples: transmitting data in clear text, weak algorithms, hardcoded keys.

hacker tip: sniff network traffic, look for weak TLS or plaintext secrets.

A03:2021 – Injection

User-supplied data is not validated, filtered, or sanitized. Examples: SQL, NoSQL, OS command, ORM, LDAP injection. Always use parameterized queries.

hacker tip: try ' OR '1'='1 or ; ls — but only on your own lab.

A04:2021 – Insecure Design

Missing or ineffective control design. Not all flaws come from implementation – some are design-level flaws like missing rate limiting or business logic abuse.

hacker tip: abuse workflows, replay actions, bypass intended flows.

A05:2021 – Security Misconfiguration

Missing hardening, unnecessary features enabled, default accounts, verbose errors, missing security headers. Very common.

hacker tip: check for default pages, directory listing, stack traces.

A06:2021 – Vulnerable and Outdated Components

Using libraries, frameworks, or software with known vulnerabilities. Patch management is critical.

hacker tip: fingerprint versions, search for public exploits.

A07:2021 – Identification and Authentication Failures

Weaknesses in authentication and session management: credential stuffing, weak passwords, missing MFA, session fixation.

hacker tip: brute-force with common passwords, test session expiry.

A08:2021 – Software and Data Integrity Failures

Code and infrastructure that does not protect against integrity violations. Includes insecure deserialization, unsigned updates, CI/CD flaws.

hacker tip: tamper with serialized objects, intercept update packages.

A09:2021 – Security Logging and Monitoring Failures

Insufficient logging, detection, monitoring, and active response. Breaches go unnoticed.

hacker tip: test if failed logins generate alerts – often they don't.

A10:2021 – Server-Side Request Forgery (SSRF)

Fetching a remote resource without validating the user-supplied URL. Allows attackers to coerce the server to make requests to internal services.

hacker tip: try http://169.254.169.254/ (cloud metadata) or internal IPs.
